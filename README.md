# 돌려돌려 작곡판

원판에 동전 같은 코인을 올리면, 원판이 돌면서 바늘을 지날 때마다 그 음을 연주해 주는 초보자용 작곡 앱이에요.

- 악기마다 원판 탑을 쌓아 여러 마디 곡을 만들어요
- 화음·장음·세기 코인, 5음/7음 음계와 ♯·♭
- 구간(A·B…)과 연주 순서, 4/4·3/4·6/8 박자, 셋잇단음표
- 곡 저장, 공유 링크, MP3·WAV 파일 받기
- 초보자/숙련자 모드와 따라하기 안내

## 파일 구조

- `app.html` — 화면 본문 (Claude 아티팩트에서도 이 파일을 그대로 씀)
- `index.html` — 웹사이트용 페이지. `node scripts/build.mjs`로 `app.html`에서 만들어요
- `styles.css` — 디자인
- `src/` — 앱 동작 (원판 그리기, 소리, 재생, 저장 등)
- `icons/`, `manifest.webmanifest` — 아이콘과 홈 화면 추가 설정

빌드 도구 없이 그대로 올리면 되는 정적 사이트예요.
